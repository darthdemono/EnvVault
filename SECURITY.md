# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or disclose secrets in
an issue. Use GitHub's private vulnerability-reporting form for this repository,
or contact the maintainer through the email address on the GitHub profile.

Include a minimal reproduction, affected version, impact, and any proposed
mitigation. We will acknowledge reports within seven days and coordinate a fix
and disclosure timeline with the reporter.

## Scope

UnENVerse's encrypted storage, desktop IPC, CLI redaction, server API,
authentication, authorization, and release artefacts are in scope. Please test
only against vaults and systems you own or are authorised to assess.
