# ADR-0016: UI and CLI must reach capability parity, with written exemptions

Status: accepted

## Context

A capability in one half only is a bug. The redaction policy is the _mapping_ between them (reveal ↔ `--reveal`), not an exception to them. Exemptions are recorded because an unwritten one looks exactly like an oversight

## Decision

UI and CLI must reach capability parity, with written exemptions
